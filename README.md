Лабораторная работа по курсу Java N1:
Классы для работы с матрицами комплексных чисел. 

В классах есть методы, позволяющие сложить, перемножить, разделить матрицы, транспонировать и вычислить определитель. 
К классам прилагается консольный интерфейс, позволяющий создать матрицу и задать операцию, также добавлена опция сохранения
результата (матрицы) предыдущей операции для последующих действий над ним.
